# Graph Environment Phase 2

Main additions in this build:

- Rectangular selection aware charting
- Auto-interpret mode
  - first row as series names
  - first column as X axis
  - optional row-based series mode
- Display-value plotting
  - formulas are plotted using evaluated display values instead of raw formula text
- Expanded chart controls
  - Line / Scatter / Scatter + Fit / Bar / Horizontal Bar / Area / Step / Histogram / Boxplot / Heatmap / Pie / Combo Line-Bar
- Better chart styling controls
  - title, axis labels, secondary Y label
  - line width, marker type, marker size
  - legend, grid, tight layout, log axes
  - colormap selection for heatmap
- Better analysis helpers
  - linear fit for scatter
  - Pearson r annotation
  - point annotation
  - stacked bar / stacked area
  - bar / pie labels
  - dual-axis combo chart
- Export
  - save current chart as PNG
- Preview / usability
  - series preview panel
  - selected-range summary
  - status bar numeric statistics in main window
